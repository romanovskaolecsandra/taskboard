# Звіт з лабораторної роботи №4. Git у терміналі

### Відповіді на контрольні запитання:

1. **Що змінилося у виводі git status після git add?**
   Файли перейшли зі стану невідстежуваних (Untracked) до стану підготовлених до комміту (Changes to be committed). Вони стали зеленими в терміналі, що означає їх додавання в область підготовки (staging area).

2. **Що показує git diff?**
   Команда показує конкретні зміни (додані чи видалені рядки) у текстових файлах, які ще не були додані в область підготовки за допомогою `git add`.

3. **Чим відрізняється git switch main від git merge?**
   Команда `git switch main` просто перемикає нас на головну гілку (змінює робоче оточення). Команда `git merge` об'єднує (вливає) зміни з іншої гілки в ту гілку, на якій ми зараз перебуваємо.

4. **Чому виник конфлікт і як ти його розв'язав?**
   Конфлікт виник тому, що в гілці `main` та в гілці `ukr-title` одночасно було змінено один і той самий 9-й рядок у файлі `index.html`. Його було розв'язано вручну: видалено службові мітки Git і об'єднано обидва варіанти в один красивий заголовок.
